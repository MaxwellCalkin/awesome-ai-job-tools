# Awesome AI Job Tools

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of AI-powered tools that help job seekers write better resumes, cover letters, and prepare for interviews.

Finding a job is hard. AI tools can help you apply smarter, not harder. This list focuses on tools that are actually useful — not just AI wrappers with a subscription paywall.

## Free Tools

No-cost tools that don't require signup:

- **[CoverCraft ATS Match Score](https://coverletter-ai-dun.vercel.app/tools/match)** — Paste a job description and resume, get an instant match percentage. Runs entirely in your browser.
- **[CoverCraft Keyword Scanner](https://coverletter-ai-dun.vercel.app/tools/keywords)** — Extract important keywords from any job posting.
- **[Resumake](https://resumake.io/)** — Generate a clean resume from a form. Open source.
- **[Reactive Resume](https://rxresu.me/)** — Full-featured resume builder, self-hostable.
- **[Pramp](https://www.pramp.com/)** — Free peer mock interviews.
- **[hunter.io Email Finder](https://hunter.io/)** — Find hiring manager emails (limited free tier).

## Open Source

Projects you can self-host or contribute to:

- [JSON Resume](https://github.com/jsonresume) — Standardized resume format
- [CoverCraft AI](https://github.com/MaxwellCalkin/coverletter-ai) — AI cover letter generator
- [Keel](https://github.com/KeelDev-tech/keel) — Open-core (Apache-2.0) job-application autopilot with a truthfulness contract: it only ever claims what you tell it is true.
